# 代码审查记录 · 2026-10-18

本轮覆盖请求格式、鉴权边界、链接解析和资源使用；没有改变搜索引擎、浏览器请求配置或生产部署。参考：[JSON-RPC 2.0](https://www.jsonrpc.org/specification)、[HTTP 鉴权语义](https://www.rfc-editor.org/rfc/rfc9110.html#section-11.1)。

## 已修复

| 问题 | 证据与处理 |
| --- | --- |
| 链接查询参数被改变 | 回归测试确认原逻辑丢失分号参数、改写 `%20` 并重排参数；现在仅移除已知跟踪参数，保留其他参数的原始字节及顺序。 |
| SOCKS 握手忽略取消 | 模拟不回复的 SOCKS 服务可复现；改用传递 context 的拨号器，测试验证取消能终止请求。 |
| 代理健康检查误报 | HTTP(S) 代理允许省略端口，而 TCP 探测要求端口；统一规范化地址，SOCKS 缺少端口则拒绝配置。 |
| RPC 格式与错误类型不准确 | 补充版本、方法、ID、参数校验以及解析/请求/参数错误码；MCP 仅接受 POST，通知不执行工具。 |
| 搜索生命周期并发无界 | 连接数不能代表执行中的搜索数；新增默认 4 个执行名额，饱和时立即失败，退出和取消释放名额。 |
| 无法使用的 API Key 配置 | 含空白的 Key 改为启动时拒绝，数据库模式拒绝空 Token；鉴权方案名按 HTTP 语义忽略大小写。 |

读取后直接解析字节缓冲区，移除了整页 HTML 和请求体的字符串复制。没有增加自动重试、备用搜索源或把失败转换为空成功。

## 验证

回归覆盖 URL 参数保真、RPC 格式和通知、错误 Token、代理地址、SOCKS 握手取消、并发饱和/释放，以及压缩响应解码后的 2 MiB 限制。`go test -race`、`go vet` 和 Linux 构建通过；测试不调用真实搜索引擎，不据此宣称实时搜索质量或内存峰值已获保证。

## 后续缺口

- **MCP 互通**：仍是有限的 HTTP JSON-RPC 实现，缺少 STDIO、完整 Streamable HTTP、版本协商、会话/取消通知处理与真实客户端互通测试。
- **授权范围**：new-api 数据库模式只校验列出的 Token 字段，不继承上游完整用户/IP/网关策略。
- **持续维护**：DOM 和浏览器请求配置依赖上游；需要更多脱敏 HTML 样本及真实查询回归。当前限额控制并发，不提供时间窗口限速。
